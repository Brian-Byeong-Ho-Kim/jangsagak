# 장사각 (JANGSAGAK)

소상공인과 예비 창업자를 위한 공공데이터 기반 수출입·시장·상권 분석 서비스.

운영 사이트: https://www.jangsagak.com/

## 이전 상태
2026-11-24 기준 운영 화면에서 상품·시장 분석, 36개월 수입 추이, 국가별 수입, 성장률, 계절 패턴, HS코드 후보, 원가·마진 계산, 시장 리포트, 카카오 장소 검색 및 서울시 점포·개폐업 통계를 확인했다. 이는 화면 확인 기록이며 원본 코드나 API 검증 결과가 아니다.

이 저장소는 기존 서비스의 원본 소스 확보를 위한 저장소이다. 현재 원본 코드는 미등록 상태이며 배포 가능한 상태가 아니다.

## 이전 원칙
- 기존 운영 환경과 도메인 유지
- 원본 프론트엔드 및 서버 코드, 데이터와 배포 설정 확보 후 등록
- 인증키, 토큰, 비밀번호 및 개인정보는 공개 저장소에 등록하지 않음
- 테스트 환경 검증 전 운영 배포 연결 금지
- 원본 전체 검증 후 v1.0-baseline 태그 생성
